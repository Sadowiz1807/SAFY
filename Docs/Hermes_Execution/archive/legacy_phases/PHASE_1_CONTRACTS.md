## Query Check Contract
`POST /query/check` accepts user-controlled SQL/query text, selected target, database profile id, and optional workspace context. It must never execute SQL.

Required high-risk response data:
```json
{
  "check_id": "check_001",
  "risk_level": "high",
  "statement_type": "DELETE",
  "confirmation_required": true,
  "confirmation_type": "numeric_code",
  "confirmation_code_length": 4,
  "confirmation_code": "4831",
  "expires_at": "2026-06-06T10:10:00Z",
  "safety_report": {
    "target": "connected_database",
    "affected_tables": ["orders"],
    "warnings": ["This query may delete table data."],
    "permission_expectation": "Execution depends on selected database credential permission."
  }
}
```

Confirmation rules:
- `confirmation_code` is visible to UI so user can read and type it back.
- Code is backend-generated, random, numeric, exactly 4 digits.
- Code is not generated by LLM.
- Code is bound to `check_id + SQL hash + target + expiry`.
- SQL change, target change, expiry, cancellation, wrong code, or missing code blocks high-risk execution.

## Query Execute Contract
`POST /query/execute` requires:
- Valid prior `check_id`.
- Same SQL hash and target as the check.
- User decision `yes`.
- Valid `confirmation_code` when high-risk.
- Audit pre-write for high-risk.
- Selected credential permission.

If DB credential lacks permission, return `DB_PERMISSION_DENIED`. `manual_write_enabled` may remain profile metadata/UI warning; it must not silently block user query execution unless explicitly configured as a separate future policy.

## Profile Contracts
Model profile JSON stores only:
- `profile_id`, `display_name`, `provider`, `base_url`, `model`, `api_key_env`, `temperature`, `max_tokens`.

Database profile JSON stores only:
- `profile_id`, `display_name`, `dbms`, `host`, `port`, `database`, `username`, `password_env`, `ssl`, `user_query_access_mode`.

Secret rules:
- Raw API key goes only to `.env`.
- Raw DB password goes only to `.env`.
- Responses return masked secret status only.
- Logs and audit redact secrets.
- Existing profile/env var overwrite returns `PROFILE_OVERWRITE_CONFIRMATION_REQUIRED` until user confirms.
