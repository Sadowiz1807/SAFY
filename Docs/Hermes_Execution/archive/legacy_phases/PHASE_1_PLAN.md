# Phase 1 Plan - Contract-first Foundation

Source of truth: `C:/Users/ASUS/SAFY/Docs_prior_project/SAFY_source.md`

Status: historical Phase 1 planning contract. Phase 1 evidence reports record completed mock/skeleton work; this artifact remains the contract reference and does not authorize real LLM, sandbox, or database execution.

## Objective
Create executable contracts and mocks so Backend-API-Agent, Frontend-UX-Agent, and Runtime-Data-Agent can implement in parallel without misreading requirements. Phase 1 does not complete real backend execution, real LLM routing, real sandbox provisioning, or real query execution.

## Non-negotiable Decisions
- UI is chat-first with left sidebar, main chat area, and right execution sidebar.
- No quick mode or guided mode; the agent acts flexibly, asks only when required, and records safe assumptions.
- Agent connected database path remains strict read-only.
- User query box is user-controlled and executes according to selected credential permission after safety check, Yes decision, high-risk confirmation when required, and audit.
- `/query/check` never executes SQL.
- `/query/execute` requires a valid prior check.
- High-risk query checks return a backend-generated visible 4-digit numeric `confirmation_code`; it is not generated by LLM and is bound to `check_id + SQL hash + target + expiry`.
- Raw API keys and DB passwords are never returned in API responses, mocks, logs, audit, or JSON profile files.
- Profile overwrite requires explicit confirmation.
- Default domain is e-commerce when user gives no domain.
- Phase reports are gate-level reports; user is not spammed with every small task report.
