## Tests

Test source under `Tests/phase*` is kept. Generated pytest basetemp folders under `tmp/` and pytest cache files are cleanup candidates. Test-local docs, if present, are not the root README.

## Required Verification Before Cleanup

Run import/usages searches, full tests, `git status --short`, and generated artifact inventory. Do not delete uncertain source folders. Archive historical docs instead of deleting.
